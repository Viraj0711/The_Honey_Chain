# HoneyChain Platform - System Requirements Specification

## 1. Hardware Architecture (Streamlined MVP)
The physical telemetry system utilizes a refined, low-cost edge computing stack deployed inside standard Khadi and Village Industries Commission (KVIC) wooden hives[cite: 4].
*   **Edge Processor:** ESP32-S3 Microcontroller[cite: 4]. Acts as the primary data processor executing onboard Edge-AI computations.
*   **Acoustic Telemetry:** INMP441 MEMS Microphone[cite: 4]. Captures raw audio for internal behavioral analysis.
*   **Climate Telemetry:** DHT22 Temperature & Humidity Probe[cite: 4]. Monitors the central brood core climate for thermoregulation tracking and disease risk assessment[cite: 4].

## 2. Software & Application Stack
Positioned as a Software-First Platform[cite: 4], the web dashboard requires high-performance rendering for live telemetry.
*   **Frontend Framework:** React, Tailwind CSS, Vite[cite: 3].
*   **Animation Engine:** Framer Motion or GSAP to handle spring physics and dynamic state transitions.
*   **Data Visualization:** Recharts, Chart.js, or HTML5 Canvas for rendering live acoustic spectrograms.

## 3. Core Diagnostic Functionalities
The software must process the hardware payloads into actionable apicultural insights based on established epidemiological frameworks[cite: 4].
*   **Acoustic Edge-AI (FFT Analysis):**
    *   Must identify the normal baseline colony flight activity (100 Hz–220 Hz)[cite: 4].
    *   Must trigger yellow warnings for pre-swarming behavior (250 Hz–450 Hz)[cite: 4].
    *   Must trigger red critical alerts for queen piping or distress signals (340 Hz–500 Hz)[cite: 4].
*   **Climate & Pathogen Risk:**
    *   Must track hive humidity against local weather to alert beekeepers of dampness risks, specifically to prevent Chalkbrood infections[cite: 4].
*   **Software-Level Security (Oracle Alternative):**
    *   Must utilize mobile keystores (TLS 1.3 ECDSA secp256k1 digital signatures & HMAC-SHA256 timestamp hashes) to authenticate data integrity prior to blockchain insertion[cite: 4].
