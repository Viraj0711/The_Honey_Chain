# HoneyChain Platform - UI/UX Design Specification

## 1. Design Concept: "Midnight Apiary" & "Digital Field Journal"
The dashboard merges industrial hardware monitoring with the organic feel of a beekeeper's field logbook. It avoids static layouts in favor of continuous, ambient motion and high-contrast diagnostic readouts.

## 2. The 60-30-10 Color Scheme
*   **60% Primary Base (`#16181D` - Deep Charcoal):** The overarching canvas background. Provides a dark, cinematic contrast that prevents eye strain while making active data glow.
*   **30% Secondary Surface (`#2A241D` - Smoked Wood):** Used for metric cards, data containers, and navigation elements. Subtle warm undertones reference the physical KVIC wooden hive environment[cite: 4].
*   **10% Accent Array:**
    *   **Amber (`#F5A623`):** Primary accent for active, healthy telemetry (e.g., live acoustic waveforms, normal status icons).
    *   **Crimson (`#FF4747`):** Reserved exclusively for critical, actionable alerts (e.g., Queen distress, theft, high pathogen risk)[cite: 4].

## 3. Typography Strategy
*   **Primary Display: 'Passion One'**
    *   *Usage:* Massive metric readouts, system headers, and hardware identifiers (e.g., **"210 Hz"**, **"HIVE 04"**).
    *   *Effect:* Imparts a heavy, stamped, industrial aesthetic to the raw hardware data.
*   **Secondary Narrative: 'Playwrite Belgique Wallonie-Bruxelles Guides'**
    *   *Usage:* Automated diagnostic logs, system recommendations, and edge-AI interpretations.
    *   *Effect:* Creates an organic, handwritten logbook aesthetic, humanizing the machine data.

## 4. Dynamic & Interactive Elements (Non-Static UI)
*   **Cinematic Ambient Background:** A looped macro video of a hive entrance or drifting pollen particles, overlaid with an 85% opacity `#16181D` filter (`mix-blend-mode: multiply`). Provides constant, fluid motion while preserving the dark UI base.
*   **Kinetic Flight Cursor:** A cursor graphic of the native *Apis cerana indica* (Indian Hive Bee)[cite: 4]. Programmed with spring-physics lag (via Framer Motion/GSAP) and trigonometric rotation (`Math.atan2`) so the bee smoothly flies and turns toward the mouse pointer's destination.
*   **Living FFT Spectrogram:** A continuously scrolling wave-graph representing the INMP441 microphone audio spectral density[cite: 4]. The line glows amber during normal baseline states and shifts to a jagged, pulsing crimson during high-frequency distress events[cite: 4]. 
*   **Diagnostic Feed Terminal:** An event log where system insights (written in the cursive 'Playwrite' font) fade in dynamically, emulating live, handwritten field notes generated by the ESP32 diagnostics.
